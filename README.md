# Grudge Ledger

> Turn flaky friends into a tiny social tax office.

Grudge Ledger is a web app where friends invite each other and log canceled plans, late replies, and forgotten favors. Every debt grows a visible cobweb on their profile and can be paid off with a sincere apology. The weirdest twist is that your own grudge meter unlocks increasingly passive-aggressive receipt templates as it rises.

## Features
- Friend invitations with shared grudge ledgers and cancel-plan forms
- Cobweb avatar that thickens based on unpaid social debt
- Apology receipts generated with escalating passive-aggressive tones
- Weekly debt report that can be shared or burned with a button

## Stack
- React
- Node.js
- PostgreSQL
- Socket.IO

## Getting started
```
npm install; set DATABASE_URL for PostgreSQL and JWT_SECRET; npm run db:migrate; npm run dev for React and Node/Socket.IO.
```
